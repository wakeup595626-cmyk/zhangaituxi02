# Contributing

English | [中文](CONTRIBUTING.zh.md)

Thank you for your interest in this project!

## Ways to contribute

- **Report a bug**  open a [GitHub Issue](https://github.com/wakeup595626-cmyk/zhangaituxi02/issues) with your Unreal Engine version, the steps to reproduce and what you expected.
- **Improve the docs**  the README exists in English and Chinese; corrections to either side are welcome.
- **Send a pull request**  see below.

## Development

1. Install **Unreal Engine 5.8**.
2. Right-click `zhangaituxi02.uproject`  *Generate Visual Studio project files*.
3. Build once from the solution, then open the project in the editor.

`Binaries/`, `Intermediate/`, `Saved/` and `DerivedDataCache/` are regenerated locally and are intentionally not tracked.

## Pull requests

- Keep each pull request focused on a single change.
- Do not commit engine build output (`Binaries/`, `Intermediate/`, `Saved/`, `DerivedDataCache/`).
- Do not add third-party marketplace assets  for licensing reasons they cannot be redistributed here. Reference them in the README instead.
- Update both `README.md` and `README.zh.md` when documented behaviour changes.
